# Good Practices for Software Development – Review

## Question 1

### Which point(s) were new to you?

* I learned that using group chats instead of private messages is a good idea. This is because it keeps things clear and the whole team is informed.

* I learned how to ask good technical questions. For example, instead of saying “it isn’t working,” I should clearly explain the problem and state what I have done so far. This is important because it saves time and shows professionalism.


* I also learned that turning on the camera during meetings helps build a better connection with teammates. This is important in building teamwork.

* Another important thing that I learned is that if a task is given to someone in the team, that person should own the task responsibly and inform the team if they have any difficulties.

## Question 2

### Which area do you think you need to improve on? What are your ideas for making progress in that area?

Where do you think you need to improve? How do you plan to improve in this area?

I think I mainly need to improve in communication and focus.

Sometimes I find it hard to ask questions early and prefer to figure everything out on my own. This may cost me some valuable time. In the future, I plan to ask questions early if I get stuck.
